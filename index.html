Sync between phones

Both phones enter the same project address, key and trip code. Changes merge within a minute, item by item, newest wins. Anyone with the code can read and change the trip, so treat it like a password. Needs a free Supabase project, see SYNC-SETUP.md in the download.

Google Maps

With your own Maps JavaScript API key the map switches to Google Maps with English labels. Needs a Google Cloud project with billing enabled; usage for two phones stays inside the free monthly allowance. Does not work inside Claude, only in Safari or the home screen app.

Add places from Google My Maps

In Google My Maps choose Export to KML (not KMZ). GeoJSON files work too. Places are added to the list, nothing is replaced.
